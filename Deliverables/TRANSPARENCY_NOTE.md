Generative AI tools were used in the creation of this project and its associated documents. The division of labor is structured as follows:

* **Source Code & System Architecture:** The foundational code and software architecture were initially generated using AI. Subsequently, the entire system was manually reviewed, corrected, adapted to our specific requirements, and expanded by us.
* **Other Project Deliverables:** All other deliverables, documentation, and project results were created entirely by hand by the project team.
